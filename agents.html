What is an AI agent?

A chatbot answers a question. An agent gets a goal and works toward it. It can look things up, run a calculation, or check a calendar, then decide what to do next. Three parts make one:

Part 1

A model

The language model that reads the goal and decides what to do.

+
Part 2

Tools

Small functions it can call, like a calculator or a weather lookup.

+
Part 3

A loop

Keep going until the job is done: decide, act, look at the result.

    Try it

    Build one in about 30 lines

    This Python program is a real agent with one tool, a calculator. The loop asks the model what to do, runs the tool if it asks for one, and sends the result back until the model gives a final answer.

    1. Get an API key

      Create an account at the Anthropic Console and make a key. An adult needs to do this step. Keep the key secret and never paste it into a document or a public page.

    2. Install the library

      In a terminal: pip install anthropic. Then set your key: export ANTHROPIC_API_KEY="your-key".

    3. Save and run the program

      Copy the code below into a file called agent.py and run python agent.py.

    agent.py 
    # A tiny agent: one model, one tool, one loop.
import anthropic

client = anthropic.Anthropic()   # reads ANTHROPIC_API_KEY

tools = [{
    "name": "calculator",
    "description": "Evaluate a basic math expression, like 240 * 0.15",
    "input_schema": {
        "type": "object",
        "properties": {"expression": {"type": "string"}},
        "required": ["expression"],
    },
}]

def run_tool(name, args):
    if name == "calculator":
        expr = args["expression"]
        if "**" in expr or not set(expr) <= set("0123456789+-*/(). "):
            return "Not allowed"
        return str(eval(expr))      # toy only: see the safety section
    return "Unknown tool"

messages = [{"role": "user", "content": "What is 15% of 240, plus 8?"}]

while True:
    resp = client.messages.create(
        model="claude-sonnet-5-5", max_tokens=1024,
        tools=tools, messages=messages,
    )
    messages.append({"role": "assistant", "content": resp.content})
    if resp.stop_reason != "tool_use":
        break                         # no tool needed: we have the answer
    results = []
    for block in resp.content:
        if block.type == "tool_use":
            results.append({
                "type": "tool_result",
                "tool_use_id": block.id,
                "content": run_tool(block.name, block.input),
            })
    messages.append({"role": "user", "content": results})

print(next(b.text for b in resp.content if b.type == "text"))

    Things to try next: change the question, add a second tool (like a function that returns today’s date), or print each step inside the loop to watch the agent think. Model names and library details change over time, so check the current Anthropic documentation if something does not run.

    No code?

    Paste this into any AI chat and play along: “Act as an agent. I will be your calculator and your notebook. Tell me what tool you want to use and what to type in, then wait for my reply.” You will feel the loop from the inside.

    For teachers

    A 40-minute lesson: be the agent

    No computers needed. Students act out the loop in groups of four, so they see why agents work and where they go wrong before they ever see code.

    Role 1

    The Brain

    Reads the goal and says out loud what to do next. Plays the model.

    Role 2

    The Hands

    Has one tool card (calculator, class schedule, or a book). Only does what the Brain asks.

    Role 3

    The Notebook

    Writes down every step. This is the agent’s memory.

    Role 4

    The Referee

    A human in the loop. Can stop the agent at any step.

    Plan

    • 5 min, hook: Ask the class to plan a field trip lunch order with a budget. Have them notice what steps they took.
    • 10 min, explain: Show the three parts and the loop from this page.
    • 15 min, act it out: Each group gets a goal, such as “How many days until the science fair, and what should we finish each week?” The Brain must say think, act, or answer each turn. The Notebook records every step.
    • 10 min, debrief: Where did the agent get stuck? Where did the Referee step in? Which answers would you not trust?

    Discussion questions

    • What is the difference between answering and acting?
    • When should a human approve a step?
    • What could go wrong if a tool gives a bad result?

    Exit ticket

    • Name the three parts of an agent.
    • Describe one task you would give an agent and one you would not.

    If you go further

    Use the code above in a supervised setting. Check your school’s policy and each tool’s age requirements first, and keep student names and personal details out of every prompt.

    Read this too

    Agents make mistakes

    Check the work. Models can sound sure and still be wrong. Verify anything that matters.

    Keep a human in the loop. Do not let an agent delete files, spend money or send messages without approval.

    Protect your key and your data. Never share an API key, and never type passwords or personal details into a prompt.

    The toy calculator is a toy. The code runs eval on text from the model. It is fine for practice with the checks above, but real programs should use a safe math parser.

    Glossary

    Words you will hear

    Agent
    A model that uses tools in a loop to reach a goal.
    Model
    The AI that reads text and writes a reply.
    Prompt
    The instructions and question you give the model.
    Tool
    A function the agent can call, like a calculator.
    Tool call
    The model asking to use a tool with specific inputs.
    Loop
    Repeating decide, act, observe until the job is done.
    Memory
    What the agent keeps track of, such as the earlier steps.
    Human in the loop
    A person who can approve or stop a step.
    API key
    A secret code that lets a program use an AI service.

    Humans and agents

    Better together

    An agent is fast and never gets bored. A person knows what matters and what is fair. The best results come when each does the part they are good at.

    The human

    Sets the goal, makes the judgment calls, and checks the work before it goes anywhere.

    The agent

    Looks things up, runs the numbers and keeps track of every step, again and again without getting tired.

    Why I care about this

    AI is growing fast, and it excites me and worries me at the same time. It is already changing how we study, work and make things, and nobody knows exactly where it goes next. That mix of curiosity and fear is what pushed me to learn how it works. I would rather understand it than just watch it happen.

    I think AI can be a real force for good when people stay in charge. An agent can take the slow, repetitive jobs, like looking things up, running numbers or keeping track of steps. That leaves people more time for the parts that need judgment, creativity and care. A person still checks the result and decides what happens next. Humans and agents working together can do more than either one alone, and that is the kind of future I want to help build.
